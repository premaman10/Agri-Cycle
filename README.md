

# 🌾 Agricycle

Agricycle is an Android application designed to support farmers by providing timely weather-based notifications and insightful analysis. Built using modern Android development tools such as **Jetpack Compose**, **WorkManager**, and **Notification Channels**, Agricycle empowers farmers to make better-informed decisions and stay updated with critical weather alerts.

## 🚀 Features

- 📍 **Weather-Based Notifications**  
  Sends alerts based on current and forecasted weather conditions using Android’s notification framework.

- 📊 **Data-Driven Analysis**  
  Offers insights based on weather patterns to help farmers plan their activities.

- 🧩 **Jetpack Compose UI**  
  A modern, reactive UI with a clean and user-friendly interface.

- 🔄 **Background Updates**  
  Utilizes **WorkManager** for periodic data fetching and updates even when the app is not in use.

- 📣 **Custom Notification Channels**  
  Ensures important alerts are delivered with the appropriate priority and sound.

## 🛠️ Tech Stack

- **Language**: Kotlin  
- **Architecture**: MVVM  
- **UI**: Jetpack Compose  
- **Background Work**: WorkManager  
- **Notifications**: Android Notification Channels  
- **API Integration**: (OpenMeteo Api , gnews.io )
